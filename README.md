# 饭点雷达 · Meal Window

> 不是「吃什么」，是「什么时候去」。
> 把「快过期的券 + 今天的活动 + 你现在几点」三个变量算成一张排序表。

命令行工具 · 零第三方依赖 · 输出 Markdown 可直接贴进日记或群聊

---

## 一句话

**点餐助手都在比「哪套便宜」，没人算「哪个时间点去最划算」。**

券有有效期、活动有日子、你只有两个饭点。这三件事叠起来，人脑算不清，于是大多数人要么错过快到期的券，要么在没活动的日子去吃。这个工具就做一件事：**排序**。

---

## 它怎么算

```
得分 = 时间贴近度
     + 到期券紧迫度 × 张数
     + 今日活动加成
```

| 因子 | 规则 | 分值 |
|---|---|---|
| 当前就在饭点内 | 11:00–13:30 / 17:00–19:30 | +40 |
| 饭点还有 0–150 分钟 | 越近越高 | +30 → +15 |
| 饭点还早（>150 分钟） | 可以先干活 | +6 |
| 已过饭点 | 扣分 | −25 |
| 今明到期的券 | 每张 | +20 |
| 今天有活动 | 每个 | +12 |

最后输出两个饭点的排名、每条的**理由**，以及一句结论（「现在就可以去」/「再过 N 分钟出发」）。

不是黑箱——每一条加分都写在下面，你能看到为什么推荐这个时段。

## 快速开始

### 直接看效果（无 Token）

```bash
python tools/meal_window.py --demo
```

### 接真实数据

```bat
set MCD_MCP_TOKEN=你的token
python tools/meal_window.py
```

### 常用参数

```bash
python tools/meal_window.py --save 今天吃啥.md   # 存成 Markdown
python tools/meal_window.py --json               # 机器可读
python tools/meal_window.py --demo --json        # 离线 JSON
```

> 需要 Python 3.9+。`tools/mcd_mcp.py` 是纯标准库 MCP 客户端，无需 `pip install`。

```markdown
## 手上的券

| 券 | 到期 | 剩余 | 状态 |
| --- | --- | --- | --- |
| 中薯买一送一 | 2026-10-22 | 今天最后一天 | 🔥 今天就用了 |
| 满 30 减 5 | 2026-10-23 | 1 天 | ⚠ 快到期 |
| 麦香鸡 9.9 元 | 2026-10-30 | 8 天 | 正常 |

## 建议

1. **首选** · 午饭（11:00–13:30）得分 92.0
   - 当前就在这个饭点内
   - 2 张券今明到期（满 30 减 5、中薯买一送一）
   - 今日有活动：限时 5 元小食
2. 备选 2 · 晚饭（17:00–19:30）得分 58.0
   - 还早，可以先干活

**结论：现在就可以去。**
```

## 用到了哪些麦当劳 MCP 工具

| Tool | 用途 | 必须 |
|---|---|---|
| `now-time-info` | 拿服务端当前时间（避免本机时钟偏差把饭点算错） | 是 |
| `query-my-coupons` | 手上的券与有效期——**这是排序的核心输入** | 是 |
| `campaign-calendar` | 活动日历，判断今天是不是活动日 | 是 |
| `available-coupons` | 上面券为空时的兜底数据源 | 否 |

详细流程见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。

## 目标用户

- **在校学生**：食堂之外就是麦当劳，券多、活动多、记不住
- **课表被切碎的人**（考研 / 考证 / 兼职 / 实验课连排）：吃饭要卡在空档里
- **习惯把计划写成 Markdown 的人**：输出直接贴进当日计划
- **管着一群人吃饭的人**（宿舍长 / 班委）：顺手看清谁有券、哪天有活动

## 技术说明

| 项 | 方案 |
|---|---|
| 形态 | Python CLI，单文件核心逻辑 |
| 依赖 | **零第三方**，只用标准库 |
| MCP 客户端 | `tools/mcd_mcp.py`（JSON-RPC + SSE 双格式） |
| 时间解析 | 兼容时间戳（秒/毫秒）、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY-MM-DDTHH:MM` |
| 字段容错 | 券/活动/时间字段各做多别名探测 |
| 无网兜底 | 连不上自动降级 `--demo`，并打印原因；绝不静默返回空表 |

## 已知限制

1. `now-time-info` 若返回结构变化导致时间解析失败，会自动改用本机时间并**打印提示**，不会悄悄用错时间。
2. 饭点窗口写死在 `MEAL_WINDOWS` 常量里（11:00–13:30 / 17:00–19:30），想改自己改一行。
3. 券的「门槛」字段目前只做展示，没有参与折扣计算——因为不知道你具体点了什么。
4. **不代为下单**，也不修改你的券状态。只读。
